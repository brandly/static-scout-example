# static-scout-example

Placeholder for an [Inspect Scout](https://github.com/meridianlabs-ai/inspect_scout) static bundle.

This repo previously hosted a static bundle (viewer + transcript/scan data) published
via GitHub Pages. It has been cleaned out — the transcript data was not intended for
public publishing — and is kept as a deployment target for a future bundle.

To redeploy: build a static scout bundle and commit its contents to `main`. GitHub Pages
serves the root of `main` (`.nojekyll` disables Jekyll processing so all asset paths are
served as-is).
